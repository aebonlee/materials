# 02 · CONTEXT MAP (Day 1 · 2교시)

> Agent 에게 무엇을 보여줄 것인가. 층마다 「넣을 것 · 뺄 것 · 언제 주나」를 적습니다.

| 층 | 무엇인가 | 넣을 것 | 뺄 것 | 언제 주나 |
|---|---|---|---|---|
| System Instruction | 역할 · 규칙 | | | 항상 (맨 위) |
| Task Context | 이번 일의 목표 · 범위 | | | 요청마다 |
| User Context | 누가 · 어떤 상황에서 | | | 요청마다 |
| Document Context | 참고 자료 · 데이터 | | | 필요한 단계에서 |
| History | 지금까지의 대화 · 결과 | | | 이어지는 일일 때 |
| Just-in-time | 그 단계에서만 필요한 것 | | | 그 단계 직전 |

## 세 벌 비교

|---|---|---|---|
| 무엇을 줬나 | | | |
| 결과에서 빠진 것 | | | |
| 결과에서 틀린 것 | | | |
| 걸린 시간 · 분량 | | | |

## 우선순위 규칙 (자료가 충돌할 때)

- 최신 자료가 오래된 자료보다 우선한다 / 1차 출처가 2차 출처보다 우선한다
- 충돌하면 고르지 말고 「확인 필요」로 표시한다
