# TS-0001 구보타 U27-4 — 안전 계통

## 증상
서부현장에서 추운 아침에 시동이 걸리지 않는다는 상담이 접수됐습니다. 계기판은 정상인데 크랭킹이 되지 않습니다.

## 확인 절차
- 계기판 점등·배터리 전압 확인
- 안전 레버가 끝까지 내려갔는지 확인
- 좌석·안전 레버 스위치 확인
- 레버 재조작 후 재시동

## 원인
안전 레버가 완전히 내려가지 않아 시동 회로가 차단된 상태(부품 고장 아님).

## 조치
전화로 안전 레버를 끝까지 올렸다 내린 뒤 시동하도록 안내.

## 결과
전화 안내만으로 즉시 시동 성공. 방문 불필요.

## 김 반장 노하우
상담 접수번호 4037. 시동 불량 신고는 안전 레버부터 확인하면 절반은 전화로 끝난다.

----------

# TS-0002 리파 R10-5 — 유압 계통

## 증상
동부현장에서 추운 아침에만 붐이 평소보다 훨씬 느리게 올라간다는 상담이 접수됐습니다. 시간이 지나면 정상이 됩니다.

## 확인 절차
- 작동유 온도·외기 온도 확인
- 작동유 규격이 계절에 맞는지 확인
- 워밍업 후 동작 속도 재확인
- 작동유 레벨·오염도 확인

## 원인
저온에 의한 작동유 점도 상승. 고장이 아니라 정상적인 물리 현상.

## 조치
시동 후 5~10분 무부하 워밍업과 전 행정 왕복을 안내하고, 방문해 계통 이상 없음을 확인.

## 결과
워밍업 절차 안내 후 재문의 없음. 방문 점검에서도 계통 정상.

## 김 반장 노하우
상담 접수번호 4052. 겨울 아침 유압 지연은 대개 점도 문제다. 데워 주면 된다.

----------

# TS-0003 밥캣 E32 — 유압 계통

## 증상
유압을 쓸 때 자갈을 긁는 듯한 소리가 난다는 보고가 있었습니다. 붐을 올릴 때 특히 심합니다.

## 확인 절차
- 작동유 레벨 게이지 확인
- 흡입 라인 조임·균열 확인
- 탱크 내 기포 확인
- 보충 전후 소리 녹음 비교

## 원인
작동유 부족으로 펌프가 공기를 빨아들여 발생한 캐비테이션.

## 조치
작동유를 규정 레벨까지 보충하고 흡입 라인 조임 확인. 보충 전후 소음을 녹음해 첨부.

## 결과
보충 직후 소음 소멸. 녹음 파일을 기록에 첨부.

## 김 반장 노하우
자갈 소리는 대개 기름이 모자라 공기를 먹는 것이다. 펌프부터 뜯지 말 것. 소리를 녹음해 두면 판단이 쉽다.

----------

# TS-0004 밥캣 E32 — 안전 계통

## 증상
가동 2,100시간 장비인데 갑자기 시동만 안 걸립니다. 계기판 표시는 이상 없습니다.

## 확인 절차
- 계기판 점등 여부와 배터리 전압 확인
- 안전 레버(록 레버)가 완전히 내려가 있는지 확인
- 좌석 스위치·안전 레버 스위치 연결 확인
- 레버를 끝까지 올렸다 내린 뒤 재시동

## 원인
안전 레버가 완전히 내려가지 않아 시동 회로가 차단된 상태. 부품 고장이 아니라 조작 순서 문제.

## 조치
안전 레버를 끝까지 올린 뒤 다시 내리고 시동. 전화로 절차를 안내해 현장에서 해결.

## 결과
안내 후 1분 만에 시동됨. 방문 없이 종결.

## 김 반장 노하우
시동 불량 신고가 오면 부품부터 의심하지 말고 안전 레버부터 물어보십시오. 절반은 여기서 끝납니다.

# TS-0008 밥캣 E32 — 전기 계통

## 증상
1,080시간 사용한 장비에서 확인됐습니다. -3도까지 떨어진 아침에 시동이 걸리지 않습니다. 크랭킹이 힘없이 돌다 멈춥니다.

## 확인 절차
- 배터리 단자 전압 측정(정상 12.4V 이상)
- 단자 부식·조임 상태 확인
- 충전 계통 발전 전압 확인(엔진 가동 시 13.8~14.4V)
- 장기 주차 여부와 전장품 소등 여부 확인

## 원인
배터리 방전. 저온에서 용량이 떨어진 데다 장기 주차로 자연 방전이 겹쳤다.

## 조치
점프 시동 후 충전, 단자 청소·조임. 전압이 회복되지 않으면 배터리 교체.

## 결과
배터리 교체 후 정상. 충전 계통은 이상 없음.

## 김 반장 노하우
겨울에는 배터리 용량이 절반까지 떨어집니다. 주말 세워 둘 때는 단자 하나 빼 두라고 하십시오.

외곽 조성현장에 임대 나가 있는 장비입니다. 수온 경고등이 뜨고 리저버 탱크가 비어 있습니다.

## 확인 절차
- 리저버·라디에이터 냉각수 레벨 확인
- 하부 누수 흔적과 냉각수 자국 확인
- 라디에이터 캡 압력 유지 확인
- 호스 클램프·워터펌프 누수 확인

## 원인
냉각수 누수로 인한 부족. 호스 클램프 이완 또는 라디에이터 캡 불량이 원인.

## 조치
누수 부위 수리(호스·클램프 교체), 냉각수 보충 및 에어 빼기, 압력 시험.

## 결과
누수 수리 후 정상. 압력 시험 통과.

----------

# TS-0060 밥캣 E32 — 엔진 계통

## 증상
2,100시간 사용한 장비에서 확인됐습니다. 과열 경고와 함께 충전 경고등도 같이 들어옵니다.

## 확인 절차
- 팬벨트 장력 측정(중앙부 처짐 12mm)
- 벨트 표면 균열·광택(슬립 흔적) 확인
- 풀리 홈 마모·이물 확인
- 장력 조정 후 수온·충전 전압 재확인

## 원인
팬벨트 슬립. 냉각팬과 알터네이터가 동시에 구동되므로 과열과 충전 불량이 함께 나타난다.

## 조치
팬벨트 장력 조정, 균열이 있으면 교체. 풀리 홈 청소.

## 결과
벨트 교체 후 소음 소멸, 수온 정상.

## 김 반장 노하우
과열이랑 충전 경고가 같이 뜨면 벨트 하나로 설명됩니다. 두 개 고장 난 게 아닙니다.

# TS-0064 밥캣 E32 — 엔진 계통

## 증상
750시간 사용한 장비에서 확인됐습니다. 힘이 없습니다. 굴착할 때 엔진이 쉽게 죽으려고 합니다.

## 확인 절차
- 에어클리너 엘리먼트 오염도 육안 확인
- 흡기 제한 표시기 확인
- 엘리먼트 청소 또는 교체 후 재시험
- 흡기 덕트 균열·이탈 확인

## 원인
에어클리너 엘리먼트 막힘으로 흡기량 부족. 분진이 많은 현장에서 주기보다 빨리 막힌다.

## 조치
엘리먼트 교체(청소는 임시 조치). 흡기 덕트 기밀 확인 후 부하 시험.

## 결과
청소 후 임시 회복, 다음 주 교체로 종결.

## 김 반장 노하우
먼지 많은 현장은 정비주기표대로 하면 늦습니다. 눈으로 보고 바꾸십시오.
