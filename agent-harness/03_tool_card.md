| 칸 | 내용 |
|---|---|
| Tool Name | (예: SEARCH · FILE READ · CALCULATOR · SPREADSHEET · DATABASE · EMAIL · CALENDAR · CODE) |
| Purpose | 이 도구로 무엇을 하는가 |
| Input | 무엇을 받아야 동작하나 |
| Output | 무엇을 돌려주나 |
| When to Use | 이 도구가 맞는 상황 |

| Failure Case | 실패하면 어떻게 보이나 · 그때 Agent 는 무엇을 하나 (멈추고 보고) |
