## 3. 검증 3단계 체크리스트 (3교시 유인물)

| 단계 | 할 일 | 내용 |
|---|---|---|
| 1단계 | 출처 묻기 | AI에게 답변의 근거와 출처를 요청한다. 출처를 대지 못하면 그 답변은 아직 확인되지 않은 것으로 본다. |
| 2단계 | 교차 확인 | 공식 자료·원문·다른 출처와 대조한다. AI가 제시한 출처가 실제로 존재하는지, 내용이 일치하는지 직접 확인한다. |
| 3단계 | 판단 기록 | 무엇을 확인했고 어디까지 믿을 수 있는지 적는다. 확인하지 못한 내용은 사실로 쓰지 않는다. |

## 4. 형성평가 퀴즈 (3문항, 객관식)

**1. 언어모델이 답을 만드는 기본 방식으로 가장 알맞은 것은?**

- ① 인터넷을 실시간으로 검색해 정답을 찾아온다
- ② 학습한 데이터를 바탕으로 다음에 올 단어를 확률적으로 예측한다
- ③ 사람이 미리 써 둔 답변 중 하나를 골라 보여 준다
- ④ 질문의 참·거짓을 논리적으로 증명한다

정답: ②

**2. AI가 존재하지 않는 출처나 사실을 그럴듯하게 지어내는 현상을 무엇이라 하는가?**

- ① 편향
- ② 과적합
- ③ 환각
- ④ 최신성 한계

정답: ③

**3. AI 답변을 검증하는 3단계 절차의 순서로 알맞은 것은?**

- ① 판단 기록 → 출처 묻기 → 교차 확인
- ② 출처 묻기 → 교차 확인 → 판단 기록
- ③ 교차 확인 → 판단 기록 → 출처 묻기
- ④ 출처 묻기 → 판단 기록 → 교차 확인

정답: ②

## 6. 유의점

- AI 도구의 화면 구성은 바뀔 수 있으므로 특정 버튼 위치를 단정하지 않고, 접속·질문·답변 확인의 흐름으로 안내한다.
- 학생이 찾은 "오류"가 실제로 오류인지 교수자가 함께 확인한다. 학생의 판단이 틀릴 수도 있다는 점 자체가 검증 교육의 일부다.
- 개인정보·타인의 저작물·민감한 정보를 AI 도구에 입력하지 않도록 실습 전에 안내한다.
- 접속이 안 되는 학생은 조원의 화면을 함께 보며 기록 역할을 맡긴다.
- 특정 회사나 서비스를 비하하지 않는다. 한계는 현재 기술이 공통으로 가진 성질로 설명한다.
